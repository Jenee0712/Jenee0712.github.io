常见错误认知

1. 与市场对抗 — 试图创造机会而非等待机会；锚定偏差使每次投资无法"归零重新开始" S05

2. 和主力硬碰硬 — 散户如"猪"跑到牛前面与熊战斗→被杀；市场四种动物：牛/熊=主力，羊=聪明散户，猪=鲁莽散户 S06

3. 无法掌握卖股时机 — 贪婪+主观判断；分批买卖法：涨时先卖50% S07

4. 不肯认错 — 卖掉赚钱股、留下亏损股（散户反向操作）；以1亿韩元为基准持股3-4项 S08

5. 光说不练 — 客观分析4支股却只买跌的那支；"股票投资是和自己的心理战" S09

6. 道听涂说 — 选举股暴涨后跌回原价或更低；"剩下的只有空壳公司和亏损" S10

7. 一知半解 — WSJ猴子射飞镖实验；股市=概率游戏，成功要素="顺应市场" S11

核心观点关联

  • 前提市场是低效率市场 + 非理性心理的组合 S14推论：散户亏损根源 = "投资原则的混乱"，不是信息不足
  • 前提股价事先反映经济趋势 S19/S43推论：景气谷底时股市已上涨；景气繁荣时股市已达高点
  • 延伸技术分析三基础（K线/均线/成交量）S26延伸：10秒选股法 + 量价八法则 + 50%原则 → 买卖时机判断
  • 延伸价值分析（PER/PBR/财报）S33-35延伸：合理总市值 = 预估净利 × 合理本益比 → 目标股价
  • 延伸股息贴现模型 P=D/(R-G) S39推论：低利率+高成长=市场涨；高利率+低成长=市场跌（经济停滞）
  • 反驳"好公司=好股票" S17好公司不等于好股票；跌势中好公司不会独自上涨；须同时判断市况+产业+个股
  • 反驳"推荐报告=买进依据" S36报告用来选公司（打造投资池），不是买进依据；实际买进由市况/产业/供需判断
  • 反驳"固定幅度停损（5%/3%一律卖）" S53停损应视个股属性+技术面+市况决定；指标股跌10%可续等，谣言小股跌1-2%就危险
  • 结论资金管理和心态控制 > 基本面/技术分析 S50终极要素：建立原则→严格执行→逐步调整；"股票投资最危险的就是失去原则"

第3部 · 技术分析

核心论断

  • 线图三基础=K线+移动平均线(5日/20日/60日)+成交量；辅助指标都以三基础为底
  • 10秒三判据：①K线颜色大小（长红K+巨量=可靠）②成交量（高量+长红K=买方强）③均线角度方向（右上+多头排列=上升趋势）
  • 均线"发散"：间隔向上扩大=短线飙涨→卖出讯号；向下扩大=短线暴跌→买进讯号
  • K线暂时落到5日均线以下="压力下跌"=最佳买入时机

核心论断

  • 买进时机=主力开始买进的时间点；卖出时机=主力开始卖出的时间点=成交量大幅增加的那天
  • "你可以隐瞒价格，但无法隐瞒成交量"
  • 量价八法则：量增+长红K=买进量；量增+长黑K=卖出量；大涨高价区激增量=转跌讯号；大跌低价圈激增量=转涨讯号

核心论断

  • 不是"外资大量买进"而是"外资抬价并大量买进"才让股价上升
  • 50%原则：10000起涨+10%至11000，买方平均价约10500；长红K后的黑K落在升幅30-50%=修正下跌（后市再涨）；跌破50%=趋势下跌
  • 前日长黑K+今日量增红K收复跌幅50%以上=更强买方进场
  • KOSPI实例：2020春50%线2100急跌至1439，反弹至50%线1900横盘数周后突破→走势转强

核心论断

  • 停顿：瞬间底盘Stop+二重多重底盘Pause；在多重底盘形成时分批买进

核心论断

  • "个股跌至第一次买进价格不该再加码，按照预测方向上涨时才能再买进"
  • 牛市早盘下跌=买进时机；空头市场下午判断买进为佳

核心论断

风险与反证

书中逻辑的失效条件、最先受损环节与传导路径

核心前提

全书体系建立在三大前提之上：资本主义不崩溃、市场可被三维度（技术+价值+市况）分析、散户可通过纪律克服非理性。任一前提崩塌，则体系失效。

风险矩阵：五大失效假设与传导链
失效假设最先受损环节传导路径书中应对
连续升息+流动性枯竭（利率长期高于成长率）市况分析层：股息贴现模型失效，P=D/(R-G)中R>G→理论价格归零升息→成长股估值塌缩→法人减仓→散户接盘→暴跌→停损触发→恐慌抛售螺旋转价值股/景气循环股；降低股票比例至20%；持有现金等待 S35/S52
技术分析滞后性加剧（算法交易主导市场，传统量价信号被操纵）技术分析层：10秒选股法/成交量判据失效算法高频交易占日成交量>10%→量价信号被"尾巴摇狗"→假突破/假跌破频发→散户按信号操作反被收割结合基本面筛选漏斗（营业利益增加率+负债比+法人净买入）过滤噪音；承认线图是"事后分析" S31/S63/S79
产业霸权转移加速（韩国主力产业被中国/东南亚全面替代）价值分析层：韩国龙头股PER/PBR锚点失效半导体/造船/显示器外流→韩国出口塌缩→韩元贬值→外资撤离→KOSPI估值体系重构投资新兴产业成长型公司；用ETF分散国别风险；关注国家转移路径中的下一站 S61/S65
黑天鹅频率超预期（十年周期危机论失准，危机间隔缩短）实战层：恐慌清单/现金储备策略来不及反应危机频密→现金储备机会成本过高→"行家投资"变成"频繁止损"→长期复利被侵蚀每月储蓄式投资成长股（摊平时点风险）；用反向ETF对冲；承认"无人能保证周期准确" S48/S60/S65
散户心理纪律无法执行（知道但做不到）全部层级：从认知到执行全面崩溃贪婪→追高→锚定→不肯认错→越摊越平→亏损50%需100%回本→心态怯懦→更大失败建立原则→实战→调整；"成为机器人"；停损最重要的不是方法而是确实遵循 S50/S51/S53

可操作结论

基于全书逻辑提炼的当前关注位置与待验证问题

当前最值得关注的 3 个位置

A 降息周期中的成长股布局窗口

当央行维持低利率或降息时（P=D/(R-G)中R下降），成长股估值空间打开。按书中逻辑：选自己熟悉的成长产业中有护城河的小型企业，每月薪资10-20%储蓄式投入，股价下跌时加买。

验证方式：跟踪FOMC/韩国金融货币委员会利率决议；确认汇率稳定（利空为短期噪音）；用技术面三基础（K线+均线+量）确认法人进场信号

B 暴跌后的"行家投资"时机

每次危机（外汇危机/IT泡沫/PIGS/2008/2020）都诞生行家收益。三件事准备：①保有一定现金（不能100%持股）②投资池（各板块龙头股，暴跌后最早反弹的是先前最强产业）③恐慌清单（具备经济护城河的企业）。

验证方式：CDS急涨→先卖危险资产→CDS下跌稳定后重新投资；确认"企业成长未变"则利空为杂音→买进时机

C 连续升息末期的防御转换

当连续升息+汇率急涨+CDS飙升同时出现时，书中明确指向股票比例降至20%、现金80%。景气好+升息环境→资产价值股/景气循环股（炼油化工造船机械钢铁）取代成长股。

验证方式：殖利率曲线变平缓或转负（10年-2年利差缩小）=未来成长不佳信号；观察外资连续净卖出方向
需要进一步验证的 3 个问题

Q1算法交易占比超过10%后，传统量价信号的有效性是否显著下降？

书中承认"线图只是事后的分析"，算法买卖规模已达数兆韩元 S40/S63。当算法占日成交量比重持续上升，10秒选股法和成交量八法则的胜率是否仍优于随机？需要用韩国市场近5年数据回测验证。

验证方式：取KOSPI前200大个股，对比"量增+长红K"信号在算法交易占比高低区间的胜率和期望收益

Q2"每月储蓄式投资成长股10年2-3亿"的复利假设在韩国市场是否成立？

书中声称每月薪资10-20%投入成长股10年可达2-3亿韩元（10倍）S48。此结论依赖韩国股市长期年化收益率>15%的假设。需要用KOSPI/KOSDAQ 2000-2025年实际数据验证定投策略的真实回报。

验证方式：模拟每月定投KOSPI 200指数+KOSDAQ 150指数，计算10年/15年/20年复合年化收益率

Q3产业霸权转移路径中，韩国下一阶段竞争力领域能否复制前代龙头的10倍涨幅？

书中列出韩国竞争力领域：5G通讯/系统半导体/自动驾驶/电动车电池/新药/次世代显示器/生技机器/网络云端 S61。但这些领域面临中国竞争加剧和地缘政治风险。需要评估哪些领域具备"护城河"（品牌/专利/网络效应/成本优势）而非仅是政策扶持。

验证方式：对比各领域龙头企业的ROE连续性（是否>15%连续3年）、负债比（<100%）、营业利益率趋势

一句话总结

人无法赢过市场，只有顺应它才能生存。建立"价值+技术+市况"三维分析框架，用纪律克服贪婪与恐惧，在暴跌时择优买进、在狂热时分批卖出——这是朴炳昌25年法人交易员经验浓缩的核心公式。
